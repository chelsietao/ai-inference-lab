AI Inference Lab

An Interactive Playground for GPU Computing and AI Inference Optimization

在 Google Colab(免費)上執行真實的 pretrained model,量測 CPU / GPU inference,並理解 latency、throughput、batch size 與記憶體。

這個網站不會執行 inference。下方圖表只是顯示「事先在特定硬體上量測並匯出」的 benchmark JSON,不是即時 GPU 運算。要自己量測,請開啟 Colab notebook。
